# OZONE UI rules

Reference: premium Gulf fit-out portfolios (especially ALEC FITOUT's project clarity) interpreted through a coordinated construction drawing set.

Tone: exact, grounded, architectural.

Audience: property owners, project leads, consultants, procurement teams, and operators evaluating whether OZONE can deliver a real fit-out, contracting, MEP, or engineering scope.

## Design brief

- Palette: mineral background `#EEF0ED`, carbon ink `#171C1B`, and OZONE teal `#19BDC6`. Concrete and steel text values are functional tints of the same neutral system.
- Type: Barlow Condensed gives display copy the direct character of site signage and drawing titles. IBM Plex Sans keeps scope, contact, and technical information easy to read.
- Layout: a twelve-column drawing-set grid with visible datum lines, offset image widths, and metadata aligned like a handover schedule. The layout is intentionally asymmetric; content is never chopped into generic rounded cards.
- Motion: one arrival language only—short ease-out image and copy entrances under 400ms. Hover movement is allowed only when it explains that an image or control is interactive. Nothing loops.
- Photography: project names are real. Until the client-approved project photographs are supplied to the web repository, clearly labelled sector-reference images may establish context but may not be represented as completed-project photographs.

## Rejections

- No gradients, glows, or gradient text.
- No icon badges, bento grids, fake dashboards, fake charts, fake logos, or fabricated testimonials.
- No stock portraits or stock people used as social proof.
- No pills, sparkle motifs, marquees, decorative loops, oversized shadows, or universal rounded corners.
- No unverified metrics, dates, scope claims, or project outcomes.
- No generic SaaS phrasing.
- No motion without a content or interaction purpose.

## Review

Before delivery, check desktop and 390px layouts, reduced motion, keyboard focus, every route, every claim, and every image label. Remove any element that can be deleted without losing information.
